<h1 align="center">🚀 DevSync</h1>

<p align="center">
  Developer Collaboration Platform — Kanban boards, team chat, project management, real-time notifications, and OAuth authentication.
</p>

## ✨ Features
🔐 JWT + OAuth2 (GitHub/Google) · OTP email verification · Rate limiting
📋 Kanban boards with drag-drop tasks
💬 WebSocket real-time chat · Team rooms & DMs
📊 Social feed with comments & likes
👥 Team management with role-based access
🔔 Real-time push notifications

## 🛠️ Tech Stack
**Backend:** Java 21, Spring Boot 3.4, MySQL 8.0, JPA/Hibernate, Flyway, WebSocket
**Frontend:** React 19, TypeScript 5, Vite, Tailwind CSS 4, shadcn/ui, Framer Motion
